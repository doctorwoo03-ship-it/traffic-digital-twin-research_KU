Research on traffic open data APIs and digital twin applications
# Traffic Digital Twin Research

## 연구 목적

도시교통 디지털트윈 구축을 위한 교통 오픈데이터 수집 및 Python 기반 API 연동 가능성을 검토하는 연구 프로젝트입니다.

## 주요 연구 내용

- ITS 국가교통정보센터 OpenAPI 제공 구조 조사
- 교통소통정보 API를 활용한 실시간 교통 데이터 수집 실험
- Python을 활용한 REST API 호출 및 응답 데이터 분석
- 표준 Node-Link와 교통상태 데이터의 연결 가능성 검토

## 활용 목적

학술연구 및 데이터 분석용으로 활용하며, 교통정보 서비스의 상용 운영을 목적으로 하지 않습니다.
